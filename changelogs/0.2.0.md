# @evoke-tech/stencil-ui-kit 0.2.0

Released 2026-11-02 · `npm install @evoke-tech/stencil-ui-kit@0.2.0`

## What's in this release

- 20 web components, two variants each: button, input, select, checkbox, radio-group, card, alert, modal, textarea, switch, tabs, badge, tooltip, toast, table, pagination, chip, progress, app-bar and quantity-stepper.
- Default Evoke look (orange `#ff5316`, navy `#0b1560`, Inter) with no theme file needed.
- Optional theme files for Tailwind, Bootstrap and Angular Material.

## Compatibility

- Angular 22.2: tested
- Vue 3.5: tested
- Plain HTML: tested
- React: expected, not run yet
- Tailwind 4.1, Bootstrap 5.3.8, Angular Material 22.2 (M3): tested

## Known issues

- Vue: dynamic text placed directly inside `<evoke-button>` removes the button's inner markup. Wrap the text in a `<span>`.
- Angular Material theme: cards and alerts render pill-shaped, and the font falls back to serif when Roboto is not loaded.
